# Levade — classical dressage school (concept site)

A concept website for **Levade**, a fictional classical dressage school near Valencia, Spain.
Designed and coded by **Kisrak Kulacoglu**.

**Live demo:** https://kisrakk.github.io/Levade/

## Features
- Split editorial hero with a two-tone title over the photo
- English / Spanish language switch (all text, including form messages)
- Schoolmaster horses, the six steps of the dressage training scale, lessons and prices
- Booking form with checks and an on-page confirmation (no data is sent)
- Livery terms and an accessible FAQ
- Responsive layout with a mobile menu; respects reduced-motion settings

## Built with
HTML · CSS · vanilla JavaScript · Google Fonts (Bodoni Moda, Pinyon Script, Hanken Grotesk)

## Note
Levade is a fictional business. Photos are placeholders for demo purposes and should be
replaced with owned or freely licensed images before public use.
